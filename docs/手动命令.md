# Piper-L 官方基线手动命令

项目：`/home/lzc/ROS2_Workspace/PiperL_Robot`。所有 ROS 命令使用本项目环境入口，默认 ROS Domain 43。

五按钮底层 CAN 面板：`bash scripts/piperl/run.sh --python-only python scripts/tools/control_panel/run.py`。
加 `--demo` 可离线查看，不连接 CAN/ROS。使用方法见 [面板说明](../scripts/tools/control_panel/README.md)。

## 1. 急停、复位与使能

确认 `can0` 已激活并对应此机械臂。以下操作由现场操作者按需执行。

```bash
# 电子阻尼急停
cansend can0 150#0100000000000000

# 复位急停：可能解除保持，操作前支撑机械臂
cansend can0 150#0200000000000000

# 六轴使能
cansend can0 471#0702000000000000
```

电子阻尼急停不保证保持当前位置；有重力负载时仍可能下落。以上命令不修改零点或限位。

**官方驱动已经启动时，手动使能使用下面的官方服务。** 驱动缓存使能状态，仅在外部发送 `cansend` 可能无法刷新缓存，导致仍拒绝控制。

```bash
cd /home/lzc/ROS2_Workspace/PiperL_Robot
bash scripts/piperl/run.sh ros2 service call /enable_agx_arm std_srvs/srv/SetBool '{data: true}'
```

等待服务成功返回，并核对六轴 motor_status 与实物保持状态后再执行规划。独立 CAN 操作仍可在未启动驱动时使用。

## 2. 六轴位置与电机速度监控

```bash
cd /home/lzc/ROS2_Workspace/PiperL_Robot
bash scripts/piperl/run.sh python scripts/tools/monitoring/read_joint_angles.py
```

直接被动接收 CAN，默认 10 Hz 刷新，显示 rad、deg、电机原始速度 rad/s、位置和速度各自的 age。
`*` 表示过期，`--` 表示未收到。Ctrl+C 退出。只看关节无需启动 ROS 驱动，不发送控制帧。表格下方新增任务格式点位；笛卡尔坐标需运行官方 MoveIt。静止后按 p 固定、s 保存、r 恢复实时点位；输出位于 outputs/points。详细说明见 [监控工具](../scripts/tools/monitoring/README.md)。

## 3. 记录手动活动观察范围

```bash
cd /home/lzc/ROS2_Workspace/PiperL_Robot
bash scripts/piperl/run.sh python scripts/tools/monitoring/read_joint_angles.py \
  --hz 5 --record-dir "outputs/joint_ranges/manual_$(date +%Y%m%d_%H%M%S_%N)"
```

按现场允许的方式手动活动，Ctrl+C 保存并退出。输出 summary.json、ranges.csv；已有目录拒绝覆盖。
可加 `--seconds 10` 限时。观察极值不是机械限位，工具不会自动写入控制器或软件限位。

## 4. 官方 CAN 激活与独立驱动

先停止使用该 CAN 的控制程序，再执行：

```bash
cd /home/lzc/ROS2_Workspace/PiperL_Robot
ip -br link show type can
# 包装器直接调用官方 can_activate.sh，can0 / 1 Mbps；脚本内部可能请求 sudo
bash scripts/piperl/activate_can.sh
ip -details link show can0

# 仅检查软件环境，不连接机械臂
bash scripts/piperl/run.sh python scripts/piperl/doctor.py

# 启动官方驱动，保持终端运行
bash scripts/piperl/start_driver.sh
```

多适配器时指定官方脚本列出的 USB bus 地址，例如 `bash scripts/piperl/activate_can.sh 1-2:1.0`，不要猜测设备。
独立驱动入口等价于在隔离环境中执行：

```bash
bash scripts/piperl/run.sh ros2 launch agx_arm_ctrl start_single_agx_arm.launch.py \
  can_port:=can0 arm_type:=piper_l effector_type:=none \
  auto_enable:=false fast_mode:=false speed_percent:=0 pub_rate:=200 control_enabled:=true
```

启动不自动使能，但 SDK 会初始化并查询硬件，不是被动监听。需要运动时按第 1 项通过官方服务手动使能。
另开终端查看一次真实反馈：

```bash
cd /home/lzc/ROS2_Workspace/PiperL_Robot
bash scripts/piperl/run.sh ros2 topic echo /feedback/joint_states --once
```

## 5. 官方 MoveIt + RViz 一键启动

第 4 项独立驱动与本项二选一。若已运行独立驱动，先 Ctrl+C 退出；CAN 无需重复重置。

```bash
cd /home/lzc/ROS2_Workspace/PiperL_Robot
# CAN 尚未激活时先执行
bash scripts/piperl/activate_can.sh
# 同时启动官方驱动、MoveIt 和 RViz
bash scripts/piperl/start_moveit.sh
```

等价官方命令：

```bash
bash scripts/piperl/run.sh ros2 launch agx_arm_ctrl start_single_agx_arm_moveit.launch.py \
  can_port:=can0 arm_type:=piper_l effector_type:=none \
  auto_enable:=false fast_mode:=false speed_percent:=0 pub_rate:=200 \
  follow:=true auto_control_gate:=false
```

现场确认后，另开终端按第 1 项调用 `/enable_agx_arm` 服务手动使能；RViz 中选择 arm、起点 current，设置目标后 Plan，检查轨迹再 Execute。
参数统一保存在 config/baseline.json，包装器只转交给官方 launch；不插入自定义轨迹执行器或保护节点。
普通模式使用 move_j；speed_percent=0 表示保留 SDK 默认速度，不代表零速度。pub_rate 是反馈频率，官方 MoveIt 控制器更新率另为 200 Hz。
官方控制转发门开启；不要同时运行其他控制话题发布者。Ctrl+C 退出程序不等同于急停。
官方驱动保留了通信恢复后按缓存状态尝试重新使能的行为，`auto_enable:=false` 仅关闭启动时自动使能；发生通信异常应退出控制程序并人工处理。
官方 Action 成功仍需与真实反馈和实物到位情况对照。本次仅完成软件基线验证，未进行实机运动验收。

## 6. 持续操作入口：单点与多点

```bash
cd /home/lzc/ROS2_Workspace/PiperL_Robot
# 首次安装/更新面板后构建一次
bash scripts/piperl/build.sh
# 启动入口，可不指定配置
bash scripts/piperl/run.sh python scripts/task/multi_point/run.py --rviz --interactive
# 或启动后自动加载并预览一个任务
bash scripts/piperl/run.sh python scripts/task/multi_point/run.py \
  --config scripts/task/multi_point/config/config.yaml --rviz --interactive
```

已有官方链路会复用；只有驱动时补启动官方 MoveIt。空闲时仍可使用官方 RViz 单点 Plan/Execute。

| 终端输入后回车          | RViz“多点任务”按钮                         |
| ----------------------- | -------------------------------------------- |
| `l /路径/config.yaml` | 选择文件 → 加载配置                         |
| `p`                   | 规划预览                                     |
| `e`                   | 确认执行（实机）                             |
| Enter                   | 重播预览                                     |
| `s`                   | 停止任务                                     |
| `m`                   | 退出多点预览，返回官方单点显示（不开控制门） |
| `r`                   | 恢复本会话停止后关闭的控制门，不继续旧轨迹   |
| `q`                   | 退出入口                                     |

每轮完成后回到等待，可再次 p → e 或切换文件。每轮都从真实当前位置重新规划，不重放上轮轨迹。执行前手动使能，多点执行中不要同时点击官方 Execute。

新开的 RViz 自动加载面板；外部 RViz 通过 **Panels → Add New Panel → piper_multi_point_rviz/TaskPanel** 添加一次。找不到插件时，用项目环境重启 RViz。更新面板后也需重新打开窗口。面板仅显示操作和简短状态，详细日志在终端；多点动画与官方单点预览分别显示。新版包含本机 RViz 时间单位修正；复用旧窗口时将显示项移入兼容分组，保留原交互目标。

停止运动后先点“恢复控制”或输入 `r`；检查成功后可单点操作，多点需重新规划。恢复不会使能或续跑旧轨迹，失败原因见终端。

虚拟障碍物加 `--scene scripts/task/multi_point/config/scene.yaml`。配置格式、日志和停止限制见[多点任务说明](../scripts/task/multi_point/README.md)。
