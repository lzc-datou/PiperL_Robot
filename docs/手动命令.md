# 常用操作速查

本页只提供常用入口。首次准备见 [环境说明](环境准备.md)，完整流程见 [文档目录](README.md)。命令在项目根目录执行，各终端使用项目环境。

## 硬件操作使用控制面板

CAN 连接、机械臂使能、重置和阻尼急停使用 [控制面板](../scripts/tools/control_panel/README.md)。先结束旧控制程序，面板完成连接、使能并确认后，再启动实机任务驱动。急停恢复先结束旧会话和驱动，面板重置、使能后重启任务。

面板可保留用于阻尼急停，运动中不要用它回零或重置。回零是单独运动，不是连接或手柄启动必需步骤。软件按钮不代替物理急停。

## 手柄控制

[连接与仿真指南](../scripts/tools/gamepad_control/README.md) 包含设备识别、单轴/笛卡尔操作、模式切换和断线检查；实机按 [首次实机操作](../scripts/tools/gamepad_control/REAL_MACHINE.md)。

```bash
PIPERL_ROS_DOMAIN_ID=64 bash scripts/piperl/run.sh python scripts/tools/gamepad_control/run.py --mode sim --input-source evdev
```

仿真应同时显示手柄窗口与 RViz。运行环境 `sim/real` 和窗口内的控制模式不同，默认单轴 J1。实际设备选择与速度参数见 [手柄参考](../scripts/tools/gamepad_control/REFERENCE.md)。

## 关节监控与点位保存

```bash
bash scripts/piperl/run.sh python scripts/tools/monitoring/read_joint_angles.py
```

关节监控只读 CAN，不需启动驱动；笛卡尔点位需要运行中的官方 MoveIt FK。静止后按 `p` 固定点位、`s` 保存、`r` 恢复实时显示。范围记录、输出和时间新鲜度要求见 [监控说明](../scripts/tools/monitoring/README.md)。

手柄抖动诊断使用监控目录的只读 `gamepad_trace.py`，在已运行会话的相同 Domain 采样，不启动或触发运动。

## 规划与执行

| 入口 | 指南 |
| --- | --- |
| 官方 RViz 单点 Plan/Execute | [单点控制](../scripts/task/single_point/README.md) |
| 持续多点操作 | [多点任务](../scripts/task/multi_point/README.md) |
| 静态障碍物与双路径比较 | [避障任务](../scripts/task/obstacle_avoidance/README.md) |
| 鼠标目标伺服 | [RViz 六轴伺服](../scripts/task/servo_tracking/README.md) |

只保留一套运动控制。手柄/鼠标专用栈不复用已有驱动；多点入口的复用策略按其指南执行。预览动画、官方 Executed 与实物到位不是同一结果。

## 构建与退出

更新 ROS 包、插件或配置后执行 `bash scripts/piperl/build.sh`，然后关闭旧入口并重启。环境、依赖更新和移机见 [环境准备](环境准备.md)。

从当前工具的停止/结束操作确认停稳，再关闭窗口或使用 `Ctrl+C`，不要用 `Ctrl+Z` 退出。程序退出、面板关闭和进程清理都不表示电机已失能。日志目录及检查结果见各入口的说明，不凭窗口消失判断实机停止。
