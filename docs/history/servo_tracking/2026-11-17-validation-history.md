# 姿态调整取消后的轨迹身份与伺服交接 · 2026-11-17

`JointMotion` 现在分别保存本 Guard 发出过的 UUID 集合和尚未确认终态的动作集合。取消计划仍立即撤销执行许可并清空当前计划，但不丢失身份；终态释放等待，晚到的接受响应不再重新添加已结束动作。未知 UUID 的活动动作仍会取消并阻止开启，旧响应仍不能重新打开控制。新增 `guard/status.other_action_active` 与 `pending_joint_actions` 便于区分外部动作和本任务待结束动作。没有修改控制算法、速度、关节限位或启动目标行为。

## 软件验证记录 · 2026-11-14（执行反馈抗饱和、DLS 与持续拖动）

本节描述当前设计，取代下文旧版“κ=17/30 减速/停止”“奇异起点自动到准备位”“同目标最多两个 IK 种子”和仅本地 TCP 抗积分饱和的说明。历史测试计数与数值保留在各轮记录，不能累加为当前版本结果。本轮没有向用户实机发送运动、使能、停止或 CAN 命令。

### 目标拖动与运动链

- 新增无 ROS 的有界 DLS 速度求解：`TCP Twist → qdot → 官方 Servo JOINT_JOG → 官方 JTC → Guard → 官方驱动`。原请求 Twist 仍发布为诊断；原生 Servo 控制输入为 JointJog。正阻尼和共同速度缩放保持输出有限，不自行插值关节位置，不改官方源码。
- 当前不按 κ 拒绝启动、恢复或在线减速/停止，也不因起点奇异自动规划到准备位。`ready_joints` 仅作为数值 IK 参考。官方 Servo 仍保留碰撞、关节速度、加速度平滑和软限位；Guard 保留真实反馈、跟踪误差、跳变、控制权、心跳及闭门保持屏障。秩亏处无法实现的瞬时方向仍可能跟不上或停滞，DLS 不是任意路径可达保证。
- 目标验证捕获位姿、原始接收时间、revision 与会话 epoch；持续更新时不取消仍在求解的快照。通过时只批准它自己的目标，不能批准最新未检查鼠标位姿。活动伺服可跟随时限内已验证快照并继续检查最新目标，避免 60 Hz 输入/45 ms IK 时“永远不是最新 revision”导致无输出。停止/换会话后的旧响应、失败或过期快照不能恢复运动。
- 最多六个数值 IK 种子：合法规划参考、前次预览、ready 数值参考、中点与两个腕部猜测。实时跟踪优先第一个完整合法解；未开启跟踪的预览、单点、恢复收集候选并兼顾关节移动量和边界余量。种子不直接驱动，也不穷举所有解；返回解仍经官方碰撞 IK、严格限位/余量和 FK 验证。
- 原生关节边界或松手后的持续停滞仍可进入同目标关节调整，使用官方规划与 action；无 κ 前提。保留每 revision 一次、目标稳定/松手、控制门关闭和旧 action 终态屏障。正常拖动不因警告改成关节规划。

### 执行反馈与抗积分饱和

`cartesian_control.py` 保留五算法，默认仍为无积分的 FF+P。PI 额外接收不可变 `ExecutionFeedback(stamp, command_time, requested_twist, limited, effective_twist, source, valid)`；六维速度均为 base_link 表达、TCP 点处的 m/s 和 rad/s，时间为同一进程的单调秒。

有效反馈必须新鲜、匹配原输出时间与完整请求、属于当前 reset 后的命令历史。默认源新鲜度 0.10 s，允许命令执行延迟 0.50 s；缺失、陈旧、倒序、跨 reset 或未匹配时不增长新积分，但允许已有积分消退。真实响应慢本身不能作为饱和证据。线速度/角速度分别判断；本地 TCP 限幅仍有条件积分、I 范数上限，到位与停止/reset 清积分。

默认 `antiwindup_mode=clamped_tracking`：回算只消除沿限幅方向已有 I，不因比例项限幅制造反向 I，不跨零；误差反向时仍可正常退出饱和。`tracking` 可选标准回算，可能留下反向积分偏置。默认回算时间常数 0.20 s，I 状态上限 0.05 m·s / 0.20 rad·s。

`execution_feedback.py` 为只读观察层，不发送控制命令：

- 精确记录控制器请求与 DLS 映射速度，已知映射损失立即反馈；另一未确认块仅冻结，不虚构速度损失。
- Servo 轨迹与 JTC reference 的完整 p/v 用 `J(q)qdot` 投影，真实关节用新位置样本差分估速。源时间戳须新鲜且推进，重复旧样本不刷新新鲜度；命令匹配使用单调接收时间，不能把 ROS 时钟当单调时钟。
- 对下游限幅要求三层新鲜、请求/映射速度稳定 0.16 s、持续能力不足 0.08 s、每层至少三个新源样本且方向稳定。判断余量为 5 mm/s / 0.025 rad/s 加 10% 参考速度；参数独立放在 control.yaml。
- 约需 0.24 s 或更长才确认稳定下游限幅；30 Hz 源可能再多等一帧。持续变速、换向或数据不足时保持未知，冻结新积分。超过该窗口预算的未建模硬件延迟仍可能与能力不足混淆；此层不测电流/力矩，不声称精确识别电机饱和。

接口、完整字段、公式与参数见 [项目结构与控制接口](../../项目结构与控制接口.md)。
