# 任务共用模块

由具体任务导入，不需要单独运行。

实机准备统一使用 [CAN 控制面板](../../tools/control_panel/README.md)：先完成 CAN 连接和六轴使能确认，再启动任务驱动。任务自身的“恢复控制”只恢复本会话控制门，不代替机械臂使能。阻尼急停后结束旧任务，按面板说明重置、使能并重新启动任务。

| 文件 | 功能 |
| --- | --- |
| schema.py | 配置、点位、障碍物校验；与监控快照共享格式 |
| joint_bounds.py | 从当前 URDF 读取六轴位置限位并验证关节值 |
| ros_context.py | ROS 生命周期、服务请求和正运动学；无 SDK/CAN 初始化 |
| robot_feedback.py | 真实反馈新鲜度、ROS 诊断等级/使能和位置稳定性判断 |
| moveit_client.py | 运行中模型、规划、官方执行 Action、取消、轨迹和目标显示 |
| planning_scene.py | 虚拟障碍物提交、坐标变换、回读与场景变化检测 |
| runtime.py | 官方链路复用/补启动、完整规划器参数复制、独立 RViz 预览与初始窗口布局、自有进程清理 |
| process_cleanup.py | Linux 自有进程组退出检查与逐级终止；启动器退出后继续处理残留子进程 |
| run_logger.py | 每次运行的配置、分段、场景和结果记录 |
| ui_theme.hpp、rviz_theme.qss、rviz_theme.qrc | 自有 RViz 面板的局部字号与控件尺寸、两行状态及全文详情，使用宿主原生 Qt 背景和控件 |
| rviz_window.hpp | RViz 首次窗口适配、主屏/当前屏窗口菜单及必要的官方侧栏外层滚动 |

新增任务复用这些接口，不复制驱动、SDK、限位或轨迹执行器。`joint1..joint6` 顺序固定；版本 1 使用官方六轴有界转动关节，其他模型须先扩展并验证。

RViz 面板调用 `piper_ui::apply(widget)`，共享 QRC 编入插件。`AdaptivePanelTheme` 随面板可用逻辑像素宽高选择字号与最小控件高度，不跟随屏幕物理分辨率猜测缩放：

| 侧栏可用尺寸 | 正文 / 按钮及状态 / 标题 | 按钮 / 停止最小高度 |
| --- | --- | --- |
| 紧凑，未达到下面条件 | 22 / 24 / 28 px | 52 / 60 px |
| 宽 ≥460 且高 ≥850 | 26 / 28 / 34 px | 64 / 72 px |
| 宽 ≥560 且高 ≥1200 | 28 / 30 / 36 px | 72 / 80 px |

状态与停止固定在顶部；正文从配置顺序排到任务操作，不把空余高度分散到组框或按钮之间。`StatusLabel` 按字体度量保留两行高度，长诊断第二行可省略；全文仍保留在控件和悬停提示中，点击或聚焦后按 Enter/空格打开非模态详情。详情不关闭控制门，也不阻止点击停止。原生背景、按钮、标签页和输入箭头由宿主 Qt 提供；样式只作用于传入面板，不覆盖官方 MotionPlanning 或 RViz 主窗口。修改共享头文件或 QSS 后需重新编译两个面板插件。

`Runtime.start_rviz` 只为本任务新建的窗口生成 `task.rviz`。生成时将上游 `Window Geometry` 整段替换为 1100 × 680 初始尺寸，不继承保存的位置、主窗口状态或停靠序列。兼容显示分组的 `Fit Window On Startup: true` 请求首次加载时按主屏可用区域适配；保存布局时该开关变为 false，尊重操作者另存的位置。上游模型、视角和规划参数不因这项布局处理改变。已有外部 RViz 仍直接复用，不修改其配置或位置。

新窗口的 **窗口 → 移到主屏幕** 可重新定位并适配系统主屏；**窗口 → 适应当前屏幕** 则保留所在屏幕调整大小。主屏由桌面的“设置 → 显示器”指定，外接屏需在那里设为主显示器。首次适配只执行一次，后续移动不会被状态刷新拉回；不设置永久最大尺寸。官方 MotionPlanning 的最小尺寸若阻止窗口缩小，在外层提供滚动区。

`PlanningScene(context, prefix=...)` 仅增删指定前缀物体，默认 `multi_point/`。纯规划任务可复用 `connect_model` 加载模型；实机任务仍通过 `connect` 检查真实反馈发布者。

持续会话和命令队列位于 `multi_point/session.py`，RViz 服务在 `session_ros.py`；单点控制仍由官方 MotionPlanning 提供。

`schema.DEFAULTS` 的速度、加速度缩放缺省值都是 0.10。随附多点配置显式设置为 0.30，随附避障配置为 0.15；装载配置时显式值优先。实际任务参数见[多点配置说明](../multi_point/README.md#可调项)和[避障配置说明](../obstacle_avoidance/README.md#配置目录与场景)。

场景草稿、应用和保存规则，以及预览反馈短暂中断的界面说明，统一见 [RViz 面板说明](../multi_point/rviz_panel/README.md)。

笛卡尔规划使用半份到位容差，实测验收使用原配置门限。`MoveItClient.stable_pose` 用新鲜关节反馈计算 FK，在同一停稳窗口内核验关节终点与 TCP 位姿；短暂超限继续观察，持续超限则超时报错，不补发运动。

`hold` 在停留期间继续核验规划终点和原始目标：关节点检查关节误差，位姿点检查 TCP 位置/姿态误差；拒绝过期 FK 样本。服务等待和已完成的异步结果仍检查取消；执行服务就绪后重新核对起点和控制器活动，再发送轨迹。

控制门恢复由显式 `recover` 操作触发：检查旧动作终止、真实反馈健康且停稳，在门关闭时经官方动作接口同步保持目标，核对输出后开门；不自动使能。
