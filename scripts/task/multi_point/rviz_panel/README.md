# RViz 多点任务面板

多点任务和避障交互入口共用 `piper_multi_point_rviz/TaskPanel`。单点规划执行仍使用官方 MotionPlanning。

## 打开面板

实机任务启动前，先在 [CAN 控制面板](../../../tools/control_panel/README.md)完成 CAN 连接和六轴使能确认，再启动任务驱动。回零不是前置步骤。正常运动中不要在控制面板点击回零、重置或重复使能；面板可保留供阻尼急停使用。阻尼急停后结束旧任务，再按控制面板说明重置、使能并重新启动任务。

首次安装或更新插件后，在项目根目录构建并启动：

```bash
bash scripts/piperl/build.sh
bash scripts/piperl/run.sh python scripts/task/multi_point/run.py --rviz --interactive
```

新窗口自动加载；旧窗口通过 **Panels → Add New Panel → piper_multi_point_rviz/TaskPanel** 添加。找不到插件时，使用项目环境重新打开 RViz。插件更新后需退出旧入口并关闭其 RViz，再重新启动，窗口不会热更新。

面板沿用 RViz / MotionPlanning 的原生 Qt 配色、灰色按钮、输入框和标签页。顶部依次显示标题、两行短状态和全宽“停止任务”或“恢复控制”，切换页面和滚动都不会把固定操作移出面板。点击状态或聚焦后按 Enter、空格可查看完整状态和诊断；悬停也可查看诊断。详细日志仍在启动终端。

字体按面板的可用逻辑像素尺寸调整：

| 可用面板 | 正文 | 按钮与状态 | 标题 | 按钮最小高度 |
| --- | --- | --- | --- | --- |
| 紧凑尺寸 | 22 px | 24 px | 28 px | 52 px |
| 至少 460 × 850 | 26 px | 28 px | 34 px | 64 px |
| 至少 560 × 1200 | 28 px | 30 px | 36 px | 72 px |

停止和恢复比同档按钮再增加 8 px 最小高度。运动与场景分为两页，正文空间不足时纵向滚动。运动页按配置、规划与执行、重播与返回单点的顺序连续排列，剩余高度留在内容之后，按钮和组间距不随高屏拉长。

任务新开的 RViz 使用 1100 × 680 初始尺寸，不继承官方配置中保存的 1200 × 975 尺寸或旧停靠状态，并在首次加载时按主屏可用区域适配。另存布局后不重复执行首次适配。旧会话目录中的 `task.rviz` 保留为历史记录，不会回写；这项修正需要重新启动任务的新窗口才能生效。实际窗口大小仍受当前屏幕和 Qt 控件最小尺寸约束。已有外部 RViz 的位置和布局由操作者管理，任务不会移动或重排它。

交互入口生成的启动配置启用 `Default Left Layout`：MotionPlanning 与多点任务在左侧共用一组标签，默认打开多点任务，侧栏目标宽度为 460–580 px。需要官方单点控制时点击 MotionPlanning 标签。Displays、Views、Help 和轨迹滑条默认隐藏，可从 Panels 菜单重新打开。布局只应用一次，之后可自由调整；另存布局时该开关保存为 false。复用外部窗口时不重排面板，也不改变 RViz 全局主题。

跨屏与缩放可用 **窗口 → 移到主屏幕**、**窗口 → 适应当前屏幕**，主屏在桌面显示器设置中选择。现有旧窗口可先用 `Super+Shift+方向键` 跨屏，或 `Alt+F7` 后移动鼠标并单击放下；快捷键以系统设置为准。新插件需要在结束旧任务后关闭并重新打开 RViz 才能加载。

运动页先选择并加载配置，再规划、预览和执行。避障入口按“无避障路径”和“有避障路径”两列显示相同的三个步骤；普通多点入口使用“规划并预览”和“执行已预览轨迹”。重播和返回单点位于流程下方。停止运动后，顶部固定区域显示“恢复控制”。按钮与终端菜单共用任务队列，状态断开时禁用任务按钮。面板本身不创建驱动，也不发送机械臂轨迹。

关闭面板不停止后台入口；退出入口用终端 `q` 或 Ctrl+C。完整任务流程见 [多点操作](../README.md)和[避障交互操作](../../obstacle_avoidance/README.md#同一窗口双路径执行与场景编辑)。

## 区分实体、目标和预览

`timed_displays.cpp` 为本机 RViz 14.1.23 修正帧时间单位，避免动画瞬间跳完、循环闪烁；其他版本直接传递原值。新窗口自动使用兼容分组；旧窗口添加面板时将现有显示项移入该分组，保留显示设置与交互目标。官方仓库和系统库不修改。

| 模型或标记 | 含义 |
| --- | --- |
| 原色不透明模型，Alpha 1.0 | 官方场景中的实测反馈姿态 |
| 原色半透明虚影，Alpha 0.35 | 单点或多点规划轨迹回放 |
| 黄色半透明模型，Alpha 0.45 | 官方单点编辑目标，与三维交互球联动 |
| 绿色目标球 | 多点静态目标，MarkerArray 话题 `/multi_point/targets` |

多点动画使用独立的 **Multi-point preview** 显示项，话题 `/multi_point/display_planned_path`；官方单点轨迹使用 `/display_planned_path`。新窗口或添加面板时自动创建多点显示项。只预览且复用未安装面板的旧窗口时，添加 **Trajectory** 并选择多点话题。绿色目标球的 Durability 选择 `Transient Local`。

多点预览暂时隐藏官方轨迹和编辑目标，保留实体模型。“返回单点”隐藏多点预览、清除标记并恢复官方显示，不重置官方交互目标。实体与虚影重合只说明姿态相近，不能仅凭动画判断实机到位。单点的 Executed 也不包含本工具多点任务的实测 TCP 到位复核。

“返回单点”仅切换显示，不开控制门。“恢复控制”检查旧动作、反馈和停稳状态，隔离同步控制器保持位置后开门；不使能、不继续旧轨迹。多点执行需重新规划。

单点轨迹默认关闭 `Loop Animation`，避免回放虚影与真实实体的位置混淆。

## 场景编辑

面板分为“运动”和“场景”两页。场景表单将 X/Y/Z、Roll/Pitch/Yaw 与各项尺寸逐列标明，数值与标签对齐。XYZ 和尺寸使用米，RPY 使用度。支持箱体、球体和圆柱，尺寸顺序分别为 box `[长,宽,高]`、sphere `[半径]`、cylinder `[高度,半径]`。表单可纵向滚动，“写入草稿”和“应用场景”紧接尺寸表单，短屏滚动到表单末尾操作；加载与另存为保持独立操作。

1. 在“场景”页点击“加载场景”，选择场景 YAML。加载只生成草稿，原碰撞场景保持生效。
2. 从物体列表选择一个物体。输入 XYZ、RPY、尺寸后，点击“写入草稿”；也可勾选“拖拽编辑”，用 RViz 的 **Interact** 工具拖动轴箭头或旋转圆环，松开后自动写入草稿。
3. 新增物体时，先点击“新增”填写表单，再点击“写入草稿”加入列表。新增名称必须唯一，已有物体名称固定。
4. 点击“应用场景”，将整份草稿同步到 MoveIt。应用会关闭拖拽手柄、作废旧预览；避障入口同时恢复有避障模式。
5. 要下次继续使用，点击“另存为”，在本任务 `config/` 下使用新文件名保存。保存内容是本任务已应用的几何场景，不是 RViz 布局，也不含其他程序管理的物体。
6. 返回“运动”页重新规划，再预览或执行。

存在未应用草稿或“拖拽编辑”仍开启时，不能规划或执行多点任务。任务处理中不接受场景编辑。新加载、新增、删除、拖动或应用都会清除旧执行确认。

已应用但未另存的场景在本次会话继续生效，重读点位不会用旧磁盘场景覆盖它；“返回单点”保留当前已应用的场景。退出后需要从另存文件加载。仅显示 Marker 不会产生碰撞物体，参与避障的几何必须同步到 MoveIt PlanningScene。

顶部状态保持两行空间，长诊断可点击或通过键盘打开全文；错误全文、场景文件路径与尺寸解释也可通过悬停提示查看。实测起点越界时，顶部显示关节名及角度，执行保持禁用；场景页不重复显示运动错误全文。

### 选择物体与草稿操作

开启“拖拽编辑”后，只在当前选中物体上显示三轴箭头和旋转圆环。可通过左侧物体下拉框选择，也可使用 RViz 顶部 Interact 点击三维物体本体切换选择；表单同步显示所选物体的位置、形状和尺寸。其他物体仍可点击，但不显示操作手柄。单纯选择不会改动草稿、碰撞场景或已有路径。

| 操作 | 更新内容 | 是否用于碰撞检测 | 是否写入文件 |
| --- | --- | --- | --- |
| 编辑表单数值 | 仅当前表单 | 否 | 否 |
| 写入草稿 | 把表单数值写入本次会话草稿 | 否 | 否 |
| 拖动手柄后松开 | 自动把新位姿写入草稿，无须再点写入草稿 | 否 | 否 |
| 应用场景 | 将整份草稿同步至 MoveIt，关闭手柄、作废旧预览 | 是 | 否 |
| 另存为 | 保存已应用的场景为新 YAML | 不改变当前场景 | 是 |

数值编辑后需先“写入草稿”，再“应用场景”；直接点击应用不会读取尚未写入草稿的表单值。想下次继续使用，应在应用后另存为。

### 勾选拖拽编辑却没有手柄

碰撞物体本体不能直接拖动，使用 **Interact** 工具操作选中物体周围的轴箭头和圆环。机械臂末端的圆环属于官方单点控制，不是障碍物手柄。

新窗口会自动创建 **Scene editor** 显示项，使用 `Interactive Markers Namespace: /multi_point/scene_editor`，命名空间末尾不加 `/update`。旧窗口若没有手柄，先重新打开 RViz；仍需手动修复时，从 **Panels → Add New Panel → Displays** 打开显示列表，展开 **Displays (time compatible) → Scene editor**，填入该命名空间，并启用显示项和 **Show Visual Aids**。

## 预览遇到反馈短暂中断

交互预览获取实测起点时，在原有最长 5 秒等待窗口内等待有效反馈，中断后重新累计停稳时间。数据年龄仍不得超过 `feedback_timeout`，字段省略时为 0.5 秒；旧样本不能替代真实起点。

持续中断显示“反馈中断 · 检查连接”。`result.json.error_details` 保存源数据年龄、接收间隔、最后时间戳和错误类别。时间戳超前、格式异常以及实机执行期间的反馈中断会立即终止当前操作；通信恢复后需重新规划，不自动恢复执行。驱动显示“连接未就绪”不能单独证明物理线缆断开，可结合控制面板的 CAN 状态及日志中的源时间戳排查。

## 接口参考

面板使用 `/piper_multi_point/command` 的 `TaskCommand` 服务和 `/piper_multi_point/status` JSON 状态，与官方话题、服务分离。面板不创建驱动或发送机械臂轨迹。

场景命令包括 `scene_load`、`scene_edit`、`scene_select`、`scene_upsert`、`scene_delete`、`scene_pose`、`scene_apply`、`scene_save`；对象 JSON 使用服务的 `path` 字段。后端验证格式、运动状态及预览身份。

普通多点的“规划并预览”和“执行已预览轨迹”仍分别发送 `plan`、`execute`。避障入口的两套路径分别使用 `plan_baseline`、`plan_avoidance`、`preview_baseline`、`preview_avoidance`、`execute_baseline`、`execute_avoidance`。对应路径已预览且缓存有效才允许执行，规划不会自动播放。任务停止关闭控制门后，顶部固定区域的“停止任务”位置显示“恢复控制”，不增加按钮排数。这是本程序的软件任务控制，不替代物理急停。
