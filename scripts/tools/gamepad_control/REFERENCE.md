# 手柄控制参考

操作步骤见 [连接与仿真](README.md)或 [首次实机操作](REAL_MACHINE.md)。本页说明运行环境、控制模式、软件参数和状态。

## 运行环境与控制模式

| 运行环境 `--mode` | 连接范围 |
| --- | --- |
| `demo` | 示例界面，不连接手柄、ROS 或机械臂 |
| `input` | 只读实体手柄，不创建运动栈 |
| `sim` | MoveIt Servo、guard、JTC、FakeSystem；不创建 SDK/CAN 实机驱动 |
| `real` | 官方实机驱动、Servo、guard 与手柄；不自动使能或回零 |

控制模式在同一窗口内选择，和 `--mode` 独立：

| 控制模式 | 输入与含义 |
| --- | --- |
| `single_axis` 单轴控制，默认 J1 | 左摇杆向上/下请求选定关节正/负速度；其他关节请求为零 |
| `cartesian` 笛卡尔控制 | 请求 `base_link` 下 TCP 线速度和角速度，经有界 DLS 变为关节速度 |

单轴模式按两行三列选轴，上排为 J1–J3，下排为 J4–J6。释放 LB/B/Y、摇杆回中且停稳后，手柄十字键左右选择同行相邻卡片，上下选择同列相邻卡片。每次按一个方向，松开后可再选。长按只移动一格，斜按或越过边缘时保留原选择。

笛卡尔符号：左摇杆前推为 `vx>0`，右推为 `vy<0`；右摇杆上推为 `vz>0`，右推为 `wz<0`；方向键上/下为 `wy` 正/负，左/右为 `wx` 正/负。需用当前实体设备核对轴符号。

笛卡尔旋转在 TCP 点发生，绕与基座轴平行的方向，不是绕基座原点公转，也不是沿工具自身轴。RPY 是当前绝对姿态显示，不是摇杆请求的角度目标。

## 主界面读数与按钮

| 显示项 | 含义 |
| --- | --- |
| 单轴模式 J1–J6 角度 | 六轴当前反馈角度，单位为度，保留三位小数；关节选择只决定左摇杆控制哪一轴，无实测速率列 |
| 笛卡尔模式 X/Y/Z | `base_link` 下 TCP 的当前位置，单位为 mm，保留一位小数 |
| 笛卡尔模式 Roll/Pitch/Yaw | TCP 相对 `base_link` 的当前绝对姿态，单位为度，保留一位小数；不是累计点动量或目标角度 |
| 速度百分比 | 当前控制模式的普通点动比例；两模式在会话内独立，规划回零固定为 10% |
| 状态 | 固定底栏第一行显示控制阶段，第二行显示回中条件、错误或恢复操作。点击状态可阅读完整原因 |
| 输入诊断 | 页头右侧展开后查看“字段 / 当前值”，包括轴值、LB/B/Y、设备身份和控制链诊断。固定行按需更新，最高 5 Hz，保留滚动位置与选中行。`input` 模式默认展开 |

读取不到有效反馈时，未知读数不表示零角或零位置，过期 TCP 数值也不是正常反馈。示例窗口的数字只用于布局预览。

| 按钮或按键 | 会话含义 |
| --- | --- |
| 开始控制 | 请求建立会话，仍需输入中立与新的 LB 按下 |
| 结束控制 | 撤销本次会话与运动许可 |
| 恢复控制 | 故障或 B 锁定后的明确恢复请求，不继续旧运动 |
| 停止 · B 或实体 B | 停止并锁定 |
| LB | 持续运动许可，松开撤销 |
| Y + LB | 持续保持的规划回零请求，确认、规划和运动阶段均不能松开 |

静态按键约定和故障处理集中在本文与 [操作指南](README.md)。窗口初始最大为 1280 × 820，并适配屏幕可用区域；左侧为角度选轴卡片或只读末端位姿，右侧为当前模式的手柄映射。底栏为速度和会话操作。控制窗口的“输入诊断”默认折叠，`input` 模式默认展开。“停止 · B”固定在窗口底部；它是本程序的软件停止，不替代物理急停。

## 模式切换与许可

模式切换、单轴选轴和恢复要求 LB/B/Y 释放、摇杆中立且机械臂停稳。切换清空输入、滤波和旧运动历史；重新观察中立、重新按下 LB 后才允许运动。B 锁定、反馈异常或断线不能靠切模式解除。

开始/恢复只建立会话。LB 提供持续许可，松开 LB 停止；B 停止并锁定，恢复需要明确点击。重连、旧服务完成、状态变绿都不自动恢复旧运动。

## 手柄回零

从停稳、输入中立的状态按住实体 Y + LB 满 1 秒，进入规划回零。确认、规划和运动期间持续保持两键，所有摇杆和方向键保持回中。松开任一键或偏转输入会取消；B、连接、反馈、guard 或界面心跳异常会停止锁定。取消、完成或故障后，旧规划均不续跑。

| 后端状态 | 界面与许可 |
| --- | --- |
| `HOME_ARMING` | 显示 `home_hold_progress`，从 0% 到 100%，持续按住 Y + LB 确认 1 秒 |
| `HOME_PLANNING` | MoveIt 规划并检查碰撞，仍需保持 Y + LB |
| `HOMING` | 沿已批准规划回到六轴零角目标，固定 10% 规划比例 |

回零比例独立于两模式速度设置。回零不写零点、不校准、不自动使能，也不将当前姿态标为零；规划失败或碰撞拒绝时停止，没有直接 SDK/CAN 运动的自动回退。结束控制、红色停止、关闭窗口和 Ctrl+C 同样撤销本次回零，需等待停稳确认后重新操作。

`GamepadInput.home` 表示映射后的 Y 输入。USB 默认配置中 LB、B、Y 分别读取 `BTN_TL`、`BTN_EAST`、`BTN_WEST`。蓝牙 `045e:02e0`、版本 `0903` 且按键位连续的布局中，这三键分别读取 `BTN_WEST`、`BTN_EAST`、`BTN_NORTH`。输入端按总线、设备标识、版本及实际支持的按键选择配置。换连接方式后，先在 `input` 窗口逐个核对实体 LB、B、Y。

## 速度与响应

[config/config.yaml](config/config.yaml) 保存软件限速与响应参数，[设备 profile](config/flydigi_direwolf2.yaml) 保存 evdev 映射。修改后重启，不在活动会话中更改映射。

| 项目 | 软件上限 | 默认 20% |
| --- | ---: | ---: |
| 单轴关节速度 | 1.50 rad/s，约 85.9°/s | 0.30 rad/s，约 17.2°/s |
| 笛卡尔平移向量 | 0.30 m/s | 60 mm/s |
| 笛卡尔右摇杆角速度 | 1.50 rad/s，约 85.9°/s | 0.30 rad/s，约 17.2°/s |
| 笛卡尔方向键旋转 | 上述角速度再乘 0.35 | 约 6.0°/s |
| 关节加速度 | 1.50 rad/s² | 下游独立约束 |

两种控制模式各自使用默认 20% 比例。只有释放 LB/B/Y 后可调节比例；回零固定 10%，不读取这两项比例。单轴关节上限参考多点任务默认规划速度，TCP 上限参考现有 Servo；它们是软件请求边界，不是测得的硬件速度或认证安全速度。比例同时缩放速度请求与关节速度上限，组合 TCP 输入按向量范数限幅。

摇杆先做死区和连续曲线映射，再使用 **40 ms 时间常数**的输入低通；下游 Servo 保留关节加速度平滑。停止、故障、模式/选轴变化时清除旧滤波历史，不允许用长尾延长 LB/B 或断链许可。滤波能减少输入突变，不能单凭这项改动保证实机无抖动。

关节边界根据当前位置与制动距离收紧向外速度，用共同缩放因子限制整组请求。笛卡尔模式优先保留解算方向，无法继续时整组速度可能为零。Servo 最后一级仍可整体阻断，边界警告不单独锁住会话，反向请求可以退回。该软件约束不是经认证的安全停止。

## 主要命令参数

| 参数 | 含义 |
| --- | --- |
| `--mode demo/input/sim/real` | 运行环境，控制模式由窗口选择 |
| `--list-devices` | 列出兼容设备并退出，不启动窗口或 ROS |
| `--device usb` / `--device bluetooth` / `--device 路径` | 按 USB 或蓝牙总线自动查找，也可指定 evdev 路径或稳定链接。按总线查找支持启动后接入 |
| `--input-source evdev/fixture` | 实体或模拟输入。sim 默认使用 `fixture`，指定设备时使用 `evdev`；real 默认使用 `evdev` |
| `--rviz/--no-rviz` | sim 默认显示三维窗口，real 默认关闭 |
| `--verified-link/--verified-mapping` | 仅在当前连接方式与映射实际确认后用于 real |

未指定 Domain 时，项目入口使用 43；操作指南使用 64。Domain 不隔离 CAN。程序对同一 Domain 的已有专用控制栈拒绝重复启动。

## 状态与排查

| 情况 | 操作 |
| --- | --- |
| 等待中立或 LB | 释放 LB/B/Y，所有摇杆回中，停稳后重新按 LB |
| 回零确认、规划或运动 | 持续保持 Y + LB；释放任一键或偏转输入取消，B 停止锁定 |
| 方向受限 | 减小输入或反向退回，核对关节边界，不提高限位绕过 |
| B、断线或异常锁定 | 处理原因，等待有效反馈确认停稳，再明确恢复 |
| 停稳未知 | 不继续操作，现场确认机械臂与停止手段 |
| 设备未发现/权限不足 | 分别检查数据连接与该手柄读取权限 |
| 只见输入图，无机械臂 | 确认运行 sim，并查看本次 RViz 启动日志 |
| 轻微抖动 | 用 [只读监控](../monitoring/README.md) 对照输入、请求与实测反馈，不能仅看动画断定来源 |

恢复前等待本次停止确认。关节或 TCP 读数、停止与方向限制信息在主界面；原始输入、设备信息和诊断在页头可展开的“输入诊断”中。

### 关闭、取消与重新启动

结束控制、窗口红色停止、关闭窗口和启动终端的 `Ctrl+C` 都会撤销当前运动许可及本次规划回零。正常退出完成后，启动终端返回提示符。`Ctrl+Z` 只挂起进程，不是退出；挂起后在原终端用 `fg` 恢复，再正常结束。

启动器拒绝同一 Domain 中的重复 `/piper_servo` 控制栈。Domain 不隔离 CAN，换 Domain 不会解决同一机械臂被多个程序控制的问题。实机发生阻尼急停后，先结束旧手柄会话与驱动，再按 [实机操作](REAL_MACHINE.md) 使用控制面板恢复并重启；不在旧控制会话中回零、重置或重复使能。

## 开发接口

窗口通过 `/piper_servo/gamepad/select_control` 的 [SelectGamepadControl.srv](../../task/servo_tracking/srv/SelectGamepadControl.srv) 请求选择，字段为 `control_mode` 和 `joint_index`，响应包含 `success`、`message` 和 `revision`。后端执行同样的停稳、中立、LB/B/Y 与锁定检查，不能绕过窗口限制。日常操作使用窗口，不需要直接调用服务。

backend 状态区分运行环境 `mode` 与控制模式 `control_mode`，另含 `selected_joint`、`selection_revision`、两模式 `speed_scales`、限速和反馈状态。回零确认进度使用 `home_hold_progress`，输入包含 `home`；普通 JointJog 和规划回零均由 guard 独立持有执行许可。

回零复用 `/piper_servo/guard/plan_joint_target`，固定 `purpose=home`、六轴零角目标与 10% 规划比例。手柄请求还携带本次闭门状态的 `guard_epoch`，guard 在入口比对自己的 `epoch`；停止后才到达的旧请求会被拒绝。普通 Servo 任务不使用这一手柄专用字段。回零完成后再走一次停止屏障，确认停稳与旧 Action 终态后返回等待许可，不保留可执行的旧计划。
