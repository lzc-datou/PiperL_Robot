# 手柄首次控制实机

先完成 [可见的仿真验证](README.md)。本页命令在项目根目录执行，不自动使能、回零或校准。当前实机验证状态见 [验证矩阵](VALIDATION.md)。

## 1. 确认已完成仿真

在 `sim + evdev` 中确认：

- 单轴 J1–J6 的正负方向和选轴行为正确，其他关节不被输入驱动。
- 笛卡尔六个自由度与正负方向符合预期。
- 只读输入窗口已单独核对实体 Y 对应 Y/home，松开 Y 后输入恢复，其他按键不误触发 Y。
- 两模式切换要求释放 LB/B/Y、中立、停稳；切换后不会自动运动。
- 按住 LB 才运动，松开 LB 停止；B 锁定需明确恢复。
- 当前连接方式断开后停止锁定，重连后不自动继续。
- 仿真回零的 1 秒确认、规划、执行及松开 Y/LB、偏转输入取消已确认；取消后的旧计划不继续。

只看到手柄读数不等于完成运动验证。无线接收器仍插着时的手柄失联需单独确认。两个 `--verified-*` 参数只是操作者对当前完整映射与连接方式的确认，不执行校准或断线测试。旧版未包含 Y 的映射确认需要补查本项。

## 2. 先用控制面板连接并使能

结束仿真和旧运动会话，等待终端返回。退出占用该机械臂的旧驱动、SDK 或其他运动任务，不靠换 Domain 绕过 CAN 冲突。

按 [控制面板说明](../control_panel/README.md) 打开面板，选择实际适配器，完成“CAN 连接”。确认安装、运动空间和现场停止手段后，点击“机械臂使能”，等待“CAN 运动模式和六轴使能已确认”。

**先面板使能，再启动实机手柄栈。** 官方驱动启动时读取使能状态，驱动运行后外部使能不保证刷新其内部缓存。面板回零不是准备步骤，不用回零确认连接。

当前模型为 PiPER-L、无末端执行器、零 TCP 偏移；装有工具、相机或支架时，先核对模型、碰撞外形及 TCP 与实物一致。

## 3. 启动手柄实机栈

只有第 1 步确实通过，才使用两个已验证参数：

```bash
PIPERL_ROS_DOMAIN_ID=64 bash scripts/piperl/run.sh python scripts/tools/gamepad_control/run.py --mode real --input-source evdev --verified-link --verified-mapping --rviz
```

多个手柄时添加 `--device 实际路径`。此命令创建官方驱动、Servo、guard、手柄窗口及 RViz，不自动前往仿真初始姿态。等待新鲜真实关节反馈，核对模型与实物姿态；反馈、模式或使能状态异常时先结束控制并处理原因。

## 4. 从单轴低速开始

1. 保持默认“单轴控制”、J1，先把本模式速度设为 5%。
2. 点击“开始控制”，松开 LB/B/Y、摇杆回中至少 150 ms。
3. 按住 LB，轻推左摇杆一个方向，短暂运动后松开 LB，观察实物停止。
4. 停稳、释放 LB/B/Y 后再选其他轴，逐项确认方向和停止。测试 B 停止与明确恢复。
5. 停稳、中立且释放 LB/B/Y 后切“笛卡尔控制”，把该模式速度也设为 5%，重新回中并按 LB。先单个平移方向，再检查旋转。

两模式比例独立。RPY 只显示当前绝对姿态；旋转在 TCP 点绕基座轴方向发生。5% 是软件比例，不是认证安全速度。平顺性、真实停止响应和距离需要现场观察，仿真结果不能替代。

面板可以保留用于阻尼急停。运动会话中不要点面板回零或重置，也不要同时打开另一套运动控制。停止状态未知或运动与输入不符时，使用现场物理急停并排查。

## 5. 需要回零时使用 Y + LB

回零不是连接或使能确认步骤。先核对模型、TCP、碰撞场景和六轴零角目标与实物一致，并完成前面的 Y 映射与仿真取消检查。

1. 让机械臂停稳，释放 LB/B/Y，全部摇杆和方向键回中。
2. 按住 Y + LB 满 1 秒，窗口显示确认进度。继续保持两键，等待 MoveIt 规划及执行。
3. 回零固定使用 10% 规划比例，与两模式当前的 5% 或其他滑条比例独立。规划和运动期间都需要持续保持 Y + LB。
4. 松开 Y 或 LB，或偏转摇杆、方向键，即取消本次回零；B、失联、反馈或界面异常会停止锁定。取消后等待停稳，松开全部按键并回中，再从头发起，旧规划不会恢复执行。

回零将六轴运动到官方 MoveIt 零角目标，不写零点、不校准、不自动使能。规划失败或碰撞拒绝时保持停止，没有直接 SDK/CAN 运动的自动回退。界面的“结束控制”、红色停止、关闭窗口或 Ctrl+C 同样终止本次任务。

## 6. 结束与急停恢复

正常结束：点击“结束控制”，观察机械臂停稳，再关闭窗口或按 `Ctrl+C`，等终端返回。关闭 RViz 也会触发本次后台退出，正常结束从手柄窗口操作。

急停恢复：先结束旧控制会话和驱动，确认机械臂得到必要支撑，再按面板说明重置、使能并等待确认，最后重新启动手柄控制。重启后重新回中、建立会话和按下 LB，不续跑旧命令。

关闭程序或面板不表示电机已失能。软件保持、面板阻尼急停和设备断电不同，收机按设备规程处理。本机日志位置和状态含义见 [参数参考](REFERENCE.md#文件与输出)。
