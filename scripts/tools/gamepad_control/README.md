# 手柄连接与虚拟机械臂测试

本指南使用实体手柄操作 FakeSystem 虚拟机械臂，不连接机械臂或 CAN。命令在项目根目录执行，首次使用先完成 [环境准备](../../../docs/环境准备.md)。

## 先看懂窗口与按键

控制窗口按“读数、控制、停止”排列，操作说明集中在本指南。页头右侧的“输入诊断”按需展开，不在映射区常驻。只读 `input` 窗口用于检查输入，没有运动按钮，“输入诊断”默认展开。

| 区域 | 内容 |
| --- | --- |
| 页头 | 运行环境、连接情况、“单轴控制”和“笛卡尔控制”按钮，以及“输入诊断”。鼠标悬停高亮，移开恢复，后台确认后切换选中状态 |
| 左侧，单轴控制 | 六张可点选的 J1–J6 卡片显示角度（°），保留三位小数。后台确认选轴后，对应卡片变色并显示勾号 |
| 左侧，笛卡尔控制 | X/Y/Z，单位为 mm；Roll/Pitch/Yaw，单位为度；六格读数均保留一位小数 |
| 右侧“手柄映射” | 单轴页标明点动与选轴方式，笛卡尔页按左摇杆、右摇杆、方向键列出平移和旋转映射 |
| 底部操作栏 | 速度、固定两行的会话状态、开始／结束／恢复按钮。回中、限位和回零进度在状态区原位更新，点击可展开完整说明，详情打开时仍可操作停止 |
| 底部 | 全宽红色“停止 · B”，内容滚动时仍可操作 |

日常操作遵守以下按键约定：

| 输入或按钮 | 作用 |
| --- | --- |
| 开始控制 | 建立控制会话；不会直接运动，也不使能或回零 |
| 按住 LB | 持续允许运动；松开立即撤销运动许可 |
| B 或“停止 · B” | 停止并锁定，不会在松开 B 后自动继续 |
| 恢复控制 | 原因处理完成且停稳后，手动恢复会话；重新回中、重新按 LB 才能运动 |
| 结束控制 | 结束当前会话并停止；下次需要重新开始 |
| 持续按住 Y + LB | 停稳、输入回中后保持 1 秒，确认并执行规划回零；全程保持，松开任一键取消 |

切换模式、选轴、调整速度或恢复前，先释放 LB/B/Y，让摇杆和方向键回中并等待停稳。速度比例只影响普通点动；规划回零固定为 10%。软件停止按钮不替代物理急停。

## 1. 连接并检查输入

蓝牙手柄先在 Ubuntu 蓝牙设置中连接，也可使用 USB 数据线或接收器。列出可读手柄及其连接方式：

```bash
bash scripts/piperl/run.sh --python-only python scripts/tools/gamepad_control/run.py --list-devices
```

飞智冰原狼的蓝牙模式可能显示为 `Xbox Wireless Controller`，USB 模式可能显示为 `Microsoft X-Box 360 pad`。实体输入窗口启动后自动检索手柄，手柄稍后才连接也能识别。用 `--device bluetooth` 仅查找蓝牙手柄，`--device usb` 仅查找 USB 手柄。蓝牙重连会重新识别同一只手柄，允许设备编号变化。若有多只同类手柄，可指定列表中的设备路径。

打开蓝牙只读窗口。使用 USB 时可改为 `--device usb`。

```bash
bash scripts/piperl/run.sh --python-only python scripts/tools/gamepad_control/run.py --mode input --device bluetooth
```

在只读窗口查看默认展开的“输入诊断”。转动摇杆并逐个按 LB/B/Y，确认字段随输入变化。特别核对：只按实体 Y 时，图中 Y 点亮、详情显示 `Y=True`，松开后恢复。此环境隐藏运动按钮，不启动 ROS 控制栈。确认后关闭窗口。无设备时检查数据连接与开机状态；无读取权限时只处理该手柄的访问权限，不开放所有键鼠设备。

固件与连接方式可能改变 Y 的映射，以只读窗口的实测为准。未核对 Y 映射前不尝试回零，旧的两模式映射确认不能替代本项。映射配置见 [手柄回零参考](REFERENCE.md#手柄回零)。

## 2. 打开虚拟机械臂

```bash
PIPERL_ROS_DOMAIN_ID=64 bash scripts/piperl/run.sh python scripts/tools/gamepad_control/run.py --mode sim --input-source evdev
```

应出现手柄窗口和 RViz 三维机械臂。只有输入图、没有三维模型时，查看本次启动日志，不能只凭轴值变化认定运动测试完成。默认仿真初始姿态来自配置，与实机姿态无关。

如果有多个手柄，在命令末尾添加 `--device 实际路径`。单独 `--mode sim` 默认使用中立的 `fixture`。使用实际蓝牙手柄控制虚拟机械臂可运行：

```bash
PIPERL_ROS_DOMAIN_ID=64 bash scripts/piperl/run.sh python scripts/tools/gamepad_control/run.py --mode sim --device bluetooth
```

## 3. 先试单轴控制

窗口初始为“单轴控制”，选中 **J1**。

1. 点击“开始控制”，松开 LB/B/Y，让摇杆回中至少 150 ms。
2. 按住 LB，轻推左摇杆上下，观察只有 J1 改变；松开 LB，观察停止。
3. 松开 LB/B/Y、摇杆回中，等待停稳。按手柄十字键选择相邻卡片，左右在同一行移动，上下在同一列移动。例如从 J2 向下选 J5，向上返回 J2。每次松开再按移动一格，到边缘停在原卡片。也可点击窗口中的 J1–J6。
4. 用同样方法逐项确认 J2–J6 的正负方向。选轴后让十字键回中，再按住 LB，用左摇杆上下点动当前关节。
5. 运动中按 B，确认停止并锁定。松开 B 不自动恢复，停稳后点击“恢复控制”，重新回中再按 LB。

默认速度比例为 20%，每种控制模式有独立比例。初次只轻推单个方向，具体软件上限见 [速度参考](REFERENCE.md#速度与响应)。

## 4. 切换到笛卡尔控制

先松开 LB/B/Y，所有运动输入回中，等待停稳，再在同一窗口选择“笛卡尔控制”。切换清除旧输入和滤波历史，需要重新按下 LB 才能运动。处于 B 锁定时不能通过切换模式解锁。

| 输入 | TCP 动作，参考系 `base_link` |
| --- | --- |
| 左摇杆前后、左右 | X/Y 平移 |
| 右摇杆上下 | Z 平移 |
| 右摇杆左右 | 绕 Z 旋转 |
| 方向键左右 | 绕 X 旋转 |
| 方向键上下 | 绕 Y 旋转 |

旋转中心在 TCP，轴方向与基座 X/Y/Z 平行。左侧 Roll/Pitch/Yaw 显示 TCP 相对基座的当前绝对姿态，不是摇杆请求的角度目标。逐项确认六个自由度及正负方向，保持 LB 才运动，松开 LB 停止。坐标与输入符号见 [控制模式参考](REFERENCE.md#运行环境与控制模式)。

接近关节边界时，控制会降低或阻断继续向外的请求，会话保持，反向输入可以退回。笛卡尔请求优先整体降速保持方向，无法实现时整组请求可能受限。不要把它理解成机械臂能跨越关节限位。

## 5. 检查断线与恢复

两种控制模式都在纯仿真中检查：

1. 按住 LB 并偏转摇杆，使虚拟机械臂运动。
2. 保持输入，关闭蓝牙手柄电源（有线模式拔掉 USB），确认虚拟机械臂停止、窗口锁定。
3. 重连，松开 LB/B/Y、摇杆回中，确认不会自动继续。
4. 停稳后手动恢复，再回中、重新按 LB 才能运动。

无线连接还需单独检查“接收器仍插着，手柄关闭或失联”。有线结果不能代替无线结果。模式切换与输入滤波不能延后 B、LB 释放或断线的停止处理。

蓝牙模式还要在仿真中先单独按住 LB，再保持 LB 并让摇杆固定偏转至少 2 秒，确认连接稳定、点动持续、松键停止。保持偏转时关闭手柄，观察从关闭到虚拟机械臂停止的实际延迟，确认锁定，重连后手动恢复。当前冰原狼通过内核蓝牙连接和 evdev 按键状态监测，持续按住无需重复按键；无线静默失联到内核确认断链可能有延迟。对于没有内核蓝牙连接节点的输入驱动，运动许可仍依赖新控制报告，出现“蓝牙运动输入报告中断”时请在只读窗口核对报告来源。两条实机命令见[启动手柄实机栈](REAL_MACHINE.md#3-启动手柄实机栈)。

## 6. 在仿真中检查 Y + LB 回零

本版增加 ROS 消息字段。升级后先关闭旧手柄窗口及其控制栈，再重新启动程序，避免新旧接口混用。

先确认实体 Y 映射，建立控制会话后松开 LB/B/Y，让全部摇杆和方向键回中并等待停稳。

1. 按住 Y + LB 满 1 秒，窗口显示回零确认进度。
2. 继续保持 Y + LB，等待规划并观察三维机械臂沿规划路径回到六轴零角目标。回零固定使用 10% 规划比例，与两模式速度设置独立。
3. 在确认、规划和运动阶段分别检查：松开 Y 或 LB，或偏转摇杆、方向键，都会取消本次回零。B、断线、反馈或界面心跳异常会停止并锁定。
4. 取消后松开全部按键、输入回中，等待停稳。确认旧规划不会继续；下次回零需要从头保持 Y + LB，普通控制也需要重新建立许可。

回零使用官方 MoveIt 零角目标并检查碰撞，不进行零点校准，也不自动使能。规划失败或碰撞拒绝时保持停止。目标或模型与实物不一致时，先处理配置，不能用回零掩盖偏差；执行链说明见 [手柄回零参考](REFERENCE.md#手柄回零)。

## 7. 结束与后续

点击“结束控制”，确认停止，再关闭窗口或在启动终端按 `Ctrl+C`。等终端回到提示符再启动下一次。不要用 `Ctrl+Z`，它会挂起进程；已经挂起时先在原终端执行 `fg`，再正常退出。

当前 Domain 已有 `/piper_servo` 时，启动器会拒绝重复创建。先检查原窗口和控制程序，不要靠更换 Domain 绕过同一机械臂的控制冲突。

完成可见运动、两模式切换、LB/B/Y 映射、回零取消和当前连接方式断线检查后，按 [首次实机操作](REAL_MACHINE.md) 继续。`--verified-link`、`--verified-mapping` 是操作者对实测结果的确认，不执行自动验证。

## 只查看布局

窗口初始最大为 1280 × 820。单轴页点角度卡片选轴，笛卡尔页按位置和姿态查看六个只读数值。窄窗口内，读数和手柄映射上下排列。“输入诊断”展开后，以最高 5 Hz 更新有变化的数值。向下滚动或选中某行即可持续查看，收起后暂停诊断显示刷新。离线交互预览使用 `run.py --mode demo`。

仅查看布局时运行：

```bash
bash scripts/piperl/run.sh --python-only python scripts/tools/gamepad_control/preview.py
```

命令在 `outputs/generated_images/gamepad_control/` 生成单轴、笛卡尔、输入检查、边界提示、锁定与回零进度的示例截图，不打开 ROS、evdev 或机械臂，也不处理控制请求。它不能替代前面的仿真与实体输入检查。共享样式见 [Qt 界面资源](../ui/README.md)。
