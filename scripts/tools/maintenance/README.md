# 项目文档审计

`audit_project.py` 只读检查第一方 Markdown，帮助维护文档链接与说明入口。只需 Python 3 标准库，不依赖 ROS。

## 运行

在项目根目录运行：

```bash
python3 scripts/tools/maintenance/audit_project.py
```

输出 JSON：

```bash
python3 scripts/tools/maintenance/audit_project.py --json
```

从其他目录运行时，可使用脚本绝对路径。默认项目目录根据脚本位置确定；`--root /path/to/project` 可指定其他项目目录。

## 检查范围与结果

扫描根目录 `README.md`，以及 `docs/`、`scripts/`、`tests/` 内的 Markdown。遍历时跳过 `external`、`.deps`、`.venv`、`piperl_ws`、`outputs`、`.git`，不跟随目录符号链接。

| 级别 | 检查项 |
| --- | --- |
| 错误 | 不存在的相对文件或目录链接 |
| 警告 | 本机绝对链接、生成结果引用、同一文档多个一级标题 |
| 警告 | 当前文档中包含 CAN 检查、CAN 激活、驱动使能或原始 CAN 发送命令 |

链接检查支持图片、内联链接、引用式链接定义、中文、带空格路径及尖括号包裹的目标。忽略链接锚点与查询参数，不验证远程链接或文档标题锚点，也不把代码块内的示例当作文件链接。命令检查保留代码块，并合并反斜杠续行。

`docs/history/` 内的历史记录仍检查链接、生成物引用和标题，但不报告操作命令。操作命令警告用于人工整理，不代表命令已执行或必须删除。

每条结果包含文件、行号和检查项。JSON 还包含扫描文件数及错误、警告数量。工具只输出到终端，不修改文件、不执行文档中的命令、不访问网络、不连接机械臂。

正常完成时，有缺失相对链接则返回 `1`，否则返回 `0`。警告不会令命令失败。参数错误使用标准退出码 `2`。
